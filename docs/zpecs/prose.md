# Prose Guidelines

How to write and organize prose.

## Writing

* Be minimal. Use fewer words or sentences when possible
* Don't repeat concepts
* Prefer the top 1000 most common words
* Use active voice
* Keep sentences simple. Avoid semicolons. Split the sentence instead
* Em dashes are fine as a list separator, like `label — description`. Avoid them mid-sentence
* Don't argue against old text. Omit it instead

## Organization

* Documents, sections, and paragraphs should have a narrow self-evident purpose
* Link content instead of repeating it
* Newlines only separate text blocks. Don't use them as line breaks
